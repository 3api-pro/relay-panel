# v2.3.0 — customer-owned infrastructure and SaaS operations

3API offers a self-hosted application manager and existing-site connection. The self-hosted panel installs Sub2API / New API on your own machine, checks its environment and supports interrupted-install retry and lifecycle management. SaaS does not provision relay hardware. Names are editable nicknames; IDs and ports are automatic.

- Account email verification/recovery, authenticator MFA, one-use recovery codes and device/session revocation.
- Team workspaces with reader/editor roles, email-bound invitations and owner-only billing.
- Personal notification preferences, retryable delivery, support tickets, refund review and CSV statements.
- Readiness checks, scheduled online panel backups with checksums, operational status and scoped audit export.
- Persistent Sub2API supplier invoice reconciliation, resumable scans, coverage indicators and historical rate estimates with correction history.

Upgrade requires additive migrations 008–012 and a verified backup. Configure `RP_DEPLOYMENT_MODE`, `RP_PUBLIC_URL`, SMTP and backup cadence. Enroll every administrator before enforcing MFA. Existing managed sites remain supported. Database connections now use UTC without rewriting historical timestamps.

Refunds require actual payment-provider action and receipts; the panel does not transfer money. Financial estimates do not prove wallet settlement or create customer debts. New API request-level supplier evidence and authoritative recharge timezone remain unavailable. Panel backups exclude remote engine data and encryption keys. Avoid rollback to pre-MFA binaries once users enroll.

See [operating instructions](../SAAS-OPERATIONS.md) and [P4 acceptance boundaries](../P4-READINESS.md). Automated tests and isolated recovery checks do not replace actual provider settlement, controlled inbox delivery or personal authenticator enrollment.
