# v2.3.1 — backup compatibility for restricted maintenance archives

Fixes scheduled PostgreSQL backups when an installation retains old maintenance archive tables that the application role cannot read. Administrators can explicitly exclude named maintenance archive tables without broadening the application database role. Core tables and wildcards cannot be excluded. The operations page and each backup manifest disclose the exclusions.

Includes all v2.3.0 local application management and SaaS features. Self-hosted users can install Sub2API / New API on their own machine; SaaS does not supply hardware. No new database migration is required beyond v2.3.0. See [the operations guide](../SAAS-OPERATIONS.md) and [v2.3.0 changes](v2.3.0.md).
