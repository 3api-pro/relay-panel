# v2.4.0 — Passive observations and site service workflows

The service center connects existing request logs with channel quality, cost review, incident handling, partner records and operational delivery. It reads existing engine management data; it does not generate model calls or channel heartbeat probes.

- Passive Sub2API/New API log readers with allowlisted evidence, deduplication, resumable pagination, bounded collection and explicit coverage/freshness. Missing data does not imply a healthy channel, and consumption logs do not establish global success rates.
- Request-level cost signals, channel/model timing summaries and scoped CSV exports. Differences are review signals, not proof of debt, loss or wallet settlement.
- Versioned incident, maintenance, upgrade, recovery, quote, settlement and onboarding cases with checklists, immutable progress history, evidence snapshots and same-site partner/support-ticket links.
- Supplier, reseller and service-operator records; quoted amounts/currencies/validity and settlement receipts. No automatic money transfers or implicit partner administrator access.
- Client configuration examples without collecting customer keys; previewed, manually published status notices that expose only the entered public text.
- Tenant/team permissions, read-only enforcement, collection controls and migration 013. Existing production data and engine behavior are retained.

See [service center](../SERVICE-CENTER.md) and [three-round planning record](../SERVICE-PLATFORM-PLAN.md). The default passive collection interval is five minutes; `RP_OBSERVATION_INTERVAL_MS=0` disables it globally and each site can pause its own collection. Log retrieval still consumes bounded network/database resources. Existing infrastructure health monitoring is separate.

Docker installation/upgrade/recovery, controlled real-provider payment and inbox delivery, and personal MFA enrollment remain subject to the existing [P4 acceptance boundaries](../P4-READINESS.md). Operational checklists document human verification; they do not substitute for those exercises.
