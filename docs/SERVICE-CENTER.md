# 站点服务中心

入口：`/services`。用户、团队编辑者和只读成员按已有站点授权访问；root 管理全平台，平台 viewer 保持全站只读。使用现有登录，不新增共享或 demo 账号。

## 被动观测

默认只读取引擎已有管理日志，不调用模型、渠道测试接口或上游合成心跳。后台间隔由 `RP_OBSERVATION_INTERVAL_MS` 控制，默认 300000 毫秒，0 关闭。每站可单独暂停自动采集；手动采集仍可使用。

每轮最多处理 10 个活动站点，每站一页、每页最多 100 条；公平轮转，站点多时实际间隔会增加。管理 API 读取仍有网络、数据库和存储开销。既有宿主机/站点存活监控独立保留，不用于推断渠道真实请求成功率。

| 来源 | 质量和费用字段 | 明确缺口 |
|---|---|---|
| Sub2API 管理端 usage | 上游账号、模型、记录扣费、账号成本、倍率快照估算、耗时、首字时间（存在时） | 消费记录不覆盖所有失败，不能推算全站成功率或 SLA |
| New API 管理端 log | 消费与错误日志、渠道、模型、记录扣费、秒级耗时 | 日志可能被关闭/清理；错误和消费可能属于同一调用；首字时间和上游成本未取得 |

不保存原始 DTO、提示词、响应正文、密钥、IP、邮箱或用户嵌套对象。来源字段按白名单归一。New API 跳过充值、退款、管理及登录日志正文，仅保留其不可逆来源指纹以验证分页覆盖。

日期按 Asia/Shanghai；保留 30 天；每站每日最多 100000 条来源记录。分页总量变化、重复页或遗漏会显示“源日志变化”，下次重扫，唯一标识避免重复计费。采集失败与渠道失败分别展示。后台仅自动读取当天；历史日期可手动分批读取。

统计和 CSV 最多包含筛选后的 10000 条样本，页面最多展示 200 条明细；超限有明确提示，可按请求编号、渠道或模型精确筛选。每个指标展示字段覆盖数。记录为空显示无证据，缺少字段保留 null，不把缺失当成零；30 分钟前的请求显示历史证据。

“本轮日志读取结束”仅表示本次分页枚举完整，不证明引擎记录了全部请求，更不证明钱包或供应商实际结算。源日志在总量不变时被替换或延迟修改仍可能影响快照，重新采集可刷新证据。

## 事件与交付

支持故障、费用复核、维护、升级、恢复、报价、结算和客户接入八种事项。请求可以附带脱敏证据快照，事项可关联同站点伙伴和归属站长的支持工单。即使请求按保留期清理，已关联事项保留证据快照。

状态：待处理 → 处理中/等待材料 → 已验证 → 已关闭，也可记录取消或重开。版本号防止并发覆盖；处理说明和检查项保留历史。标为已验证/关闭需完成全部检查，结算还需登记真实支付渠道回执。勾选和回执属于操作员声明，面板不代替供应商核验、不自动转账、不改用户余额。内部 JSON 导出包含处理记录与证据，不是对外公开页面。

升级与恢复事项是运行手册和交付记录；实际引擎操作继续使用站点管理。面板备份不包含远端引擎数据。真实 Docker 安装、升级、数据库恢复演练仍需客户测试环境，不能仅凭检查项自动通过验收。

## 合作伙伴

按站点维护上游供应商、下游代理、代运维档案、联系方式、合作范围和归档状态；报价记录金额/币种/有效期及接受依据，结算记录回执与对账检查。档案不自动授予外部登录或站点管理员权限。

v2.5.0 的 `/collaboration` 提供独立事项授权。仅站点所有者或 root 可邀请，团队编辑者不能再转授；受邀者用已验证邮箱的普通账号接受一次性邀请。邀请最长7天，授权1–90天，撤销、到期、所有者停用、站点销毁或关联伙伴归档后立即拒绝访问。供应商/代理必须关联同站点同类伙伴，所分配事项也必须关联该伙伴。

| 协作身份 | 可分配事项 |
|---|---|
| 供应商 | 故障、费用复核、报价、结算 |
| 代理 | 故障、报价、客户接入 |
| 运维 | 故障、维护、升级、恢复、客户接入 |
| 客服 | 故障、客户接入 |
| 财务 | 费用复核、报价、结算 |

所有身份均只见逐条共享的标题、说明与协作回复。内部描述、请求证据、费用、付款回执和内部历史不自动共享，也不授予站点、团队或既有财务中心权限。共享需先预览；提交结果后由站点方复核，可退回处理、关闭或撤回。协作状态不自动修改内部事项，不转账、不执行运维操作。列表与消息支持分页，历史保留供站点方查看。邀请链接由站点方自行发送，不自动寄送邮件；邀请不创建账号或绕过平台注册要求。

## 客户接入与状态公告

配置向导支持 cURL、Python SDK 和环境变量，以及 Chat Completions/Responses 示例。面板不接收客户真实密钥、不自动运行示例；实际运行会产生 API 调用，模型/协议授权由站点决定。

状态公告先预览再发布，可保存草稿或撤回。公开地址 `/public/service/<random-token>` 仅展示站长明确填写的标题、说明、人工声明状态和更新时间，不自动公开站点地址、请求、财务、伙伴和内部事件。公开内容转义、禁脚本、禁止索引且不缓存。站点销毁后公告不可访问。

## 客户知识库与模型说明

v2.6.0 的 `/knowledge` 支持按站点维护接入指南、常见问题、操作手册和模型能力记录。团队编辑者可保存草稿、查看历史和恢复旧版本；仅站点所有者或 root 可发布、撤回和启用客户帮助页。只读成员与平台 viewer 不可写。

草稿与已发布 JSON 快照独立保存；保存或恢复草稿不改变客户页面。每次保存、发布、撤回和恢复都有不可变历史，版本冲突返回 409。每站最多 500 篇，管理列表每页 50 条、历史每页 20 条、公开目录每页 40 条，支持标题、摘要和分类搜索。

站长明确启用 `/public/help/<random-token>` 后，获得链接的客户可免登录访问已发布文章。目录及文章均不缓存、不被索引，内容按纯文本转义；不自动带入站点地址、密钥、账号、日志或历史。停用帮助页、撤回文章、站点销毁或站长停用后拒绝公开访问。公开链接不是访问授权机制，请仅发布适合公开的信息。

模型说明分别记录协议、流式输出、工具调用、图像输入、结构化输出、推理参数和提示缓存。支持与不支持均需填写验证日期、引擎版本和依据；未测试保留未知。超过 30 天的记录提示重新确认。全部属于站长人工声明，不代表平台认证，也不触发模型调用或渠道心跳。

## 被动预算与阈值提醒

v2.7.0 的 `/budgets` 按站点管理最多 50 条预算，可选精确渠道和模型条件，使用记录扣费或上游成本两种口径。币种为 USD，最多六位小数；周期按北京时间日历日、周一开始的周、自然月计算。只有站点所有者或 root 可修改策略、检查阈值和确认事件，团队成员沿用站点只读访问范围。

汇总只使用当前采集批次的消费记录，错误日志不重复计入金额。缺少成本不拿用户扣费替代；没有金额证据返回未知。每日报告展示采集状态和金额字段覆盖。低于提醒线不保证总费用低于预算，采集不完整或过期会提示。事件确认仅登记复核，不代表费用恢复正常。

每次修改策略产生新版本；同一版本、同一周期仅记录新的更高阈值，防止并发重复通知。开启通知后写入站长的通知队列，并遵守已有邮箱验证、通知偏好和重试规则。后台复用观测间隔，每轮最多 5 条策略轮转，只读取面板数据库；`RP_OBSERVATION_INTERVAL_MS=0` 同时关闭预算后台检查。手动检查及 CSV 导出可用。此模块不读写引擎限额、不关闭渠道、不修改余额或自动划款，不能称为实时强制预算。

## API

- `GET /api/services/catalog`：已有站点元数据和交付检查项，不触发健康探测。
- `GET/POST /api/services/collection-settings`：按站点控制后台采集。
- `POST /api/services/collect`：读取单页现有日志，有租约及速率限制。
- `GET /api/services/quality`、`quality.csv`：按站点/日期及可选请求、渠道、模型读取证据。
- `GET/POST /api/services/work`；`GET /work/:id`；`POST /work/:id/events`；`GET /work/:id/export`。
- `GET/POST /api/services/partners`；`POST /partners/:id`（含 version）。
- `GET/POST /api/services/publication`：手动公告，发布/撤回需要写权限。

写操作均需要既有会话和工作区写权限，越权资源统一返回 404。导出同样按工作区隔离；外部公告仅通过独立、只读、随机地址访问。

## 发布验收范围

本次对四个运行中的 Sub2API 站点读取真实日志并验证管理员操作。New API 适配已通过上游字段契约和自动化测试；当前没有可用 New API 实机，实际部署兼容验收仍待环境。历史安装失败站点不参与采集。

## 财务协作范围

v2.8.0 的 `/finance-access` 为财务身份提供额外、显式的数据授权。站点所有者或 root 先在协作工作台创建财务邀请，再设置对协作者可见的名称、北京时间固定日期区间（最多 92 天）、精确渠道/模型过滤条件；上游成本、消费明细、每日 CSV 导出和提交复核分别开关，默认关闭。既有邀请与事项权限不自动扩展。团队编辑者不能再转授，协作者不能借用工作区头访问站点管理或管理员对账接口。

财务报告只查询面板已存的当前采集批次消费记录，不额外请求引擎或推理接口。每日报告包含来源、采集时间、状态与金额字段覆盖；缺失金额保持未知，成本不会用用户扣费替代。明细仅包含日期、模型、渠道及明确授权的金额字段，不返回原始请求标识、凭据或内部日志。

每次保存授权生成新版本。协作者提交复核时由服务器生成当时报告快照，同版本最多一条待处理提交；站长可确认或退回并记录对方可见的意见。快照不随日志变化覆盖；授权更新后协作者只可读取当前版本复核，站长保留旧版历史。撤销、到期、停用、邮箱未验证或站点归属变化会拒绝后续访问。记录复核不代表付款、退款、自动结算或银行账单确认；既有管理员财务复核与供应商对账功能仍保持管理员范围。

## 平台客服的工单授权

v2.9.0 扩展 `/support` 平台支持工单。工单属于客户与平台之间的会话，由 root 按单条工单分配给已有、有效且邮箱已验证的普通账号；站点协作身份不自动继承此权限。默认仅允许阅读本工单完整客户对话，可分别开启回复、结单/重新打开、内部备注。每个工单最多 10 个有效授权，单次最长 90 天，可更新权限、续期或撤销。客服邮箱变化、撤销验证、到期、停用或授权管理员失效后拒绝访问；不授予客户账户、站点、账单或其他工单权限。

内部备注单独存储，只有 root 或获准的客服可阅读和追加，客户接口不返回备注，备注也不触发客户通知。客户可见回复仍进入原工单消息与状态流转，客户和管理员保留原有权限。回复和通知原子提交，版本冲突拒绝覆盖；工单行锁让撤销与回复按事务顺序生效。授权不会创建账号，也不会自动发送邀请邮件。

工单列表支持标题搜索、状态筛选和按更新时间分页；普通账号分别查看自己的工单与分配给自己的工单。对话默认读取最新 100 条，可继续加载更早记录，不再截断 500 条后的内容；内部备注与授权历史同样支持分页。新增回复后刷新列表可获得最新排序。所有授权、撤销、内部备注和客服回复保留管理员审计，复用现有通知偏好与投递队列。


## 引擎用户限额与预算的衔接

v2.10.0 在 `/risk` 提供独立的用户限额入口与历史记录，root 可从 `/budgets` 跳转并保留站点选择。输入引擎用户编号、平台、窗口和金额后先预览；null 表示不限，0 表示该窗口拒绝请求。服务器保存预览并绑定管理员、站点连接目标与用户，十分钟内有效。前端修改任何限额字段都会作废当前确认；执行只接收该预览的 `operationId` 和 `acknowledgeScope: true`，不再接受直接传金额的旧写入方式。

默认仍为仅告警，须显式设置 `RP_RISK_ENFORCE=1` 才允许写入，只读站点始终拒绝。迁移 `019_quota_operations.sql` 增加操作记录；写入前持久化执行意图并串行检查同一用户的未决操作，再比对完整限额快照，保留其他平台与窗口。引擎配置变化时拒绝写入；成功响应后仍独立 GET 回读，回读一致才记为配置已核实。纯用量增长不视为配置冲突，三档均不限的行被引擎省略时按相同配置处理。

超时、回读差异或保存最终结果失败均不能自动重试 PUT。记录保留后，开始两分钟可只读复核；差异仍存在时，管理员确认引擎没有待执行请求，五分钟后可用最近十分钟内且仍匹配的回读记录、处理意见及明确确认关闭差异。关闭差异不标记为原写入成功。恢复备份也保留未决记录，避免重启后盲目重试。引擎自身接口没有条件写入，本面板无法原子协调其他控制台同时修改；应避免多个控制面同时管理同一用户限额。

适用语义依据 [Sub2API 计费检查](https://github.com/Wei-Shaw/sub2api/blob/dba770d56a0ee0ae5bad1b3dc5e11614d323163c/backend/internal/service/billing_cache_service.go) 与 [配额窗口实现](https://github.com/Wei-Shaw/sub2api/blob/dba770d56a0ee0ae5bad1b3dc5e11614d323163c/backend/internal/handler/quotaview/helpers.go)：标准模式余额计费的用户×平台限额，订阅流量与简易模式豁免；日、周跟随引擎时区，月为 30 天。部署版本、实际运行模式和请求拦截仍需在引擎侧验收，并发请求可能超额。本功能不把北京时间自然周期、渠道或模型预算自动转换为原生限额，不调用重置用量接口，也不增加轮询心跳、推理探测或自动限流任务。NewAPI 原生限额暂不在本入口范围。


## 合作结算单与回执（v2.11.0）

`/settlements` 提供管理方与协作者入口。站点所有者或 root 可为同站点有效伙伴创建应收/应付草稿，逐行填写 USD 或 CNY 金额，最多六位小数，允许负数折让但净额必须为正。单据不换汇；单号在同一所有者与伙伴下唯一，账期最多 366 天、明细最多 50 行。内部备注与对外说明分别保存。

财务协作中已接受、含正数上游成本的复核可生成 USD 应付草稿，固定来源账期；保留原始快照、已知成本记录和采集缺口，金额仍需人工核对。一个来源只允许一张未取消结算单，取消后可重新引用。观测成本不自动当成供应商确认金额。确认出单后内容冻结；更正需取消并重建，存在有效回执时先核实并作废错误登记。

每张单独共享前需选择已接受邀请的有效身份、预览公开单据和当前回执，再明确确认。供应商/代理须关联同一伙伴，财务身份也可接收。公开范围包含金额明细、对外说明和所有当前、后续回执；内部备注、原始账目快照、连接信息不共享。协作者可以确认或提出异议，回复仅管理方和该身份可见；其他协作者不能读取。撤销共享、协作授权撤销/到期及相关身份失效后拒绝访问，邀请本身不授予结算单访问权，也不自动发送邮件。

操作员在实际渠道核对后逐次登记回执编号、金额、日期、方式和公开说明。金额不能超过未登记余额，同一所有者下有效回执编号不能重复或跨单登记，未来日期被拒绝；每单最多 1,000 条记录（含作废）。作废保留原记录与原因，并重新计算金额；更正后可使用同一编号重新登记。页面区分未登记、部分登记、足额登记和逾期，所有状态只依据登记记录，不表示银行/支付平台到账核验，也不触发付款或退款。

单据、回执、处理历史和共享记录均可分页；CSV 导出包含公开单据和回执，并处理表格公式前缀。变更、事件和审计在同一事务中提交，金额用六位小数精确运算；版本及数据库锁防止并发覆盖，唯一约束防止跨单重复记账。


## 生命周期任务与失联复核（v2.12.0）

`/jobs` 提供全部状态筛选、旧任务分页和步骤历史。站点所有者可取消自己尚未执行的排队任务，root 可取消所有排队任务；工作区协作身份不继承此权限。取消不会执行引擎操作，运行中任务不能靠修改取消标记停止。

提交和领取任务使用数据库短事务串行检查。同一站点存在排队、运行或待复核任务时拒绝新提交；全局两个执行名额同时计入运行和待复核任务。运行租约为 60 秒，每 10 秒向面板数据库续租，时间由数据库判定。这是控制面任务占用记录，不是渠道心跳，不调用模型。健康执行进程不会因另一进程启动而被标为失败。

进程失联、执行权核对失败、执行后状态提交异常或主动关停时，任务保留为“结果待复核”，不会自动抢占或重试。Docker Compose 命令最长执行 10 分钟，执行权丢失会传递取消信号；受保护的站点和凭据写入拒绝失效执行者。取消子进程不证明 Docker 守护进程、容器操作或数据库迁移已停止，租约也不是宿主机隔离机制。

root 须先停止旧执行进程及子进程，确认容器操作不再进行，并核对现场的版本、运行状态及数据。距最后续租（无记录则取开始/创建时间）至少五分钟后，可重新预览，选择观察到的完成/未完成结果并填写依据。任务和站点记录变化后旧预览失效；复核与审计在同一事务提交。复核只记录人工结论并解除占用，不等于面板验证成功，不修改站点版本或状态，也不自动回滚、恢复或重试。需要重试时在现场确认后单独发起；安装重试仍受原站点状态限制。

升级前备份面板数据库并停止全部旧版应用/执行进程；迁移 021 添加租约、复核字段和调度互斥记录，旧版残留运行任务在新版启动后转为待复核。不要将旧版执行器与新版同时运行。PostgreSQL 协调用于同一安装、同一宿主机、相同目录及配置下的进程交接；多主机调度不在范围，PGlite 数据目录仍只允许一个应用进程。面板数据库备份包含任务占用与复核记录，恢复后须再次核对真实引擎现场；恢复面板记录不会恢复引擎数据。

隔离 PostgreSQL 的两个独立 Node 进程已验证并发提交、全局名额、单次领取、健康进程保护及强制终止后的复核。现有真实管理员完成桌面与手机端流程，受控驱动覆盖超时/取消契约；这些验证没有执行真实 Docker 安装、升级或恢复，不替代实机验收。
