# 站点服务中心

入口：`/services`。用户、团队编辑者和只读成员按已有站点授权访问；root 管理全平台，平台 viewer 保持全站只读。使用现有登录，不新增共享或 demo 账号。

## 被动观测

默认只读取引擎已有管理日志，不调用模型、渠道测试接口或上游合成心跳。后台间隔由 `RP_OBSERVATION_INTERVAL_MS` 控制，默认 300000 毫秒，0 关闭。每站可单独暂停自动采集；手动采集仍可使用。

每轮最多处理 10 个活动站点，每站一页、每页最多 100 条；公平轮转，站点多时实际间隔会增加。管理 API 读取仍有网络、数据库和存储开销。既有宿主机/站点存活监控独立保留，不用于推断渠道真实请求成功率。

| 来源 | 质量和费用字段 | 明确缺口 |
|---|---|---|
| Sub2API 管理端 usage | 上游账号、模型、记录扣费、账号成本、倍率快照估算、耗时、首字时间（存在时） | 消费记录不覆盖所有失败，不能推算全站成功率或 SLA |
| New API 管理端 log | 消费与错误日志、渠道、模型、记录扣费、秒级耗时 | 日志可能被关闭/清理；错误和消费可能属于同一调用；首字时间和上游成本未取得 |

不保存原始 DTO、提示词、响应正文、密钥、IP、邮箱或用户嵌套对象。来源字段按白名单归一。New API 跳过充值、退款、管理及登录日志正文，仅保留其不可逆来源指纹以验证分页覆盖。

日期按 Asia/Shanghai；保留 30 天；每站每日最多 100000 条来源记录。分页总量变化、重复页或遗漏会显示“源日志变化”，下次重扫，唯一标识避免重复计费。采集失败与渠道失败分别展示。后台仅自动读取当天；历史日期可手动分批读取。

统计和 CSV 最多包含筛选后的 10000 条样本，页面最多展示 200 条明细；超限有明确提示，可按请求编号、渠道或模型精确筛选。每个指标展示字段覆盖数。记录为空显示无证据，缺少字段保留 null，不把缺失当成零；30 分钟前的请求显示历史证据。

“本轮日志读取结束”仅表示本次分页枚举完整，不证明引擎记录了全部请求，更不证明钱包或供应商实际结算。源日志在总量不变时被替换或延迟修改仍可能影响快照，重新采集可刷新证据。

## 事件与交付

支持故障、费用复核、维护、升级、恢复、报价、结算和客户接入八种事项。请求可以附带脱敏证据快照，事项可关联同站点伙伴和归属站长的支持工单。即使请求按保留期清理，已关联事项保留证据快照。

状态：待处理 → 处理中/等待材料 → 已验证 → 已关闭，也可记录取消或重开。版本号防止并发覆盖；处理说明和检查项保留历史。标为已验证/关闭需完成全部检查，结算还需登记真实支付渠道回执。勾选和回执属于操作员声明，面板不代替供应商核验、不自动转账、不改用户余额。内部 JSON 导出包含处理记录与证据，不是对外公开页面。

升级与恢复事项是运行手册和交付记录；实际引擎操作继续使用站点管理。面板备份不包含远端引擎数据。真实 Docker 安装、升级、数据库恢复演练仍需客户测试环境，不能仅凭检查项自动通过验收。

## 合作伙伴

按站点维护上游供应商、下游代理、代运维档案、联系方式、合作范围和归档状态；报价记录金额/币种/有效期及接受依据，结算记录回执与对账检查。档案不自动授予外部登录或站点管理员权限。

v2.5.0 的 `/collaboration` 提供独立事项授权。仅站点所有者或 root 可邀请，团队编辑者不能再转授；受邀者用已验证邮箱的普通账号接受一次性邀请。邀请最长7天，授权1–90天，撤销、到期、所有者停用、站点销毁或关联伙伴归档后立即拒绝访问。供应商/代理必须关联同站点同类伙伴，所分配事项也必须关联该伙伴。

| 协作身份 | 可分配事项 |
|---|---|
| 供应商 | 故障、费用复核、报价、结算 |
| 代理 | 故障、报价、客户接入 |
| 运维 | 故障、维护、升级、恢复、客户接入 |
| 客服 | 故障、客户接入 |
| 财务 | 费用复核、报价、结算 |

所有身份均只见逐条共享的标题、说明与协作回复。内部描述、请求证据、费用、付款回执和内部历史不自动共享，也不授予站点、团队或既有财务中心权限。共享需先预览；提交结果后由站点方复核，可退回处理、关闭或撤回。协作状态不自动修改内部事项，不转账、不执行运维操作。列表与消息支持分页，历史保留供站点方查看。邀请链接由站点方自行发送，不自动寄送邮件；邀请不创建账号或绕过平台注册要求。

## 客户接入与状态公告

配置向导支持 cURL、Python SDK 和环境变量，以及 Chat Completions/Responses 示例。面板不接收客户真实密钥、不自动运行示例；实际运行会产生 API 调用，模型/协议授权由站点决定。

状态公告先预览再发布，可保存草稿或撤回。公开地址 `/public/service/<random-token>` 仅展示站长明确填写的标题、说明、人工声明状态和更新时间，不自动公开站点地址、请求、财务、伙伴和内部事件。公开内容转义、禁脚本、禁止索引且不缓存。站点销毁后公告不可访问。

## 客户知识库与模型说明

v2.6.0 的 `/knowledge` 支持按站点维护接入指南、常见问题、操作手册和模型能力记录。团队编辑者可保存草稿、查看历史和恢复旧版本；仅站点所有者或 root 可发布、撤回和启用客户帮助页。只读成员与平台 viewer 不可写。

草稿与已发布 JSON 快照独立保存；保存或恢复草稿不改变客户页面。每次保存、发布、撤回和恢复都有不可变历史，版本冲突返回 409。每站最多 500 篇，管理列表每页 50 条、历史每页 20 条、公开目录每页 40 条，支持标题、摘要和分类搜索。

站长明确启用 `/public/help/<random-token>` 后，获得链接的客户可免登录访问已发布文章。目录及文章均不缓存、不被索引，内容按纯文本转义；不自动带入站点地址、密钥、账号、日志或历史。停用帮助页、撤回文章、站点销毁或站长停用后拒绝公开访问。公开链接不是访问授权机制，请仅发布适合公开的信息。

模型说明分别记录协议、流式输出、工具调用、图像输入、结构化输出、推理参数和提示缓存。支持与不支持均需填写验证日期、引擎版本和依据；未测试保留未知。超过 30 天的记录提示重新确认。全部属于站长人工声明，不代表平台认证，也不触发模型调用或渠道心跳。

## API

- `GET /api/services/catalog`：已有站点元数据和交付检查项，不触发健康探测。
- `GET/POST /api/services/collection-settings`：按站点控制后台采集。
- `POST /api/services/collect`：读取单页现有日志，有租约及速率限制。
- `GET /api/services/quality`、`quality.csv`：按站点/日期及可选请求、渠道、模型读取证据。
- `GET/POST /api/services/work`；`GET /work/:id`；`POST /work/:id/events`；`GET /work/:id/export`。
- `GET/POST /api/services/partners`；`POST /partners/:id`（含 version）。
- `GET/POST /api/services/publication`：手动公告，发布/撤回需要写权限。

写操作均需要既有会话和工作区写权限，越权资源统一返回 404。导出同样按工作区隔离；外部公告仅通过独立、只读、随机地址访问。

## 发布验收范围

本次对四个运行中的 Sub2API 站点读取真实日志并验证管理员操作。New API 适配已通过上游字段契约和自动化测试；当前没有可用 New API 实机，实际部署兼容验收仍待环境。历史安装失败站点不参与采集。
